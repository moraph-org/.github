# Moraph for Good

Moraph's social impact program: free financial literacy, help reaching healthcare and nonpartisan civic education, delivered with local organizations.

- Website: https://moraph.org (volunteering: https://volunteer.moraph.org)
- Parent company: [Moraph LLC](https://www.moraph.com)

Moraph for Good gives Moraph's software, security expertise and people's time, donated or discounted, to nonprofits, community lenders, clinics and small public bodies. It is not a registered charity and does not accept donations.

## How we work

- **Issue forms.** Every repository in this organization uses the shared issue forms in this repository: Bug, Feature, Task, Epic and Initiative. Blank issues are allowed for anything that does not fit.
- **Hierarchy.** Work is organized with organization issue types and sub-issues: Initiative (a portfolio-level outcome spanning a quarter or more) > Epic (a shippable body of work) > Feature, Task or Bug.
- **Project boards.** Each product has a project board ("Moraph · <Product>") with Status (Backlog, Ready, In progress, In review, Done), Priority (P0-P3), Size (XS-XL) and two-week iterations.
- **Pull requests.** Use the pull request template and link the issue with `Closes #<n>` so it closes on merge.
- **Labels.** Shared labels such as `needs-triage`, `needs-info`, `blocked`, `security`, `accessibility`, `documentation`, plus `platform:*` and `area:*` labels per repository.
